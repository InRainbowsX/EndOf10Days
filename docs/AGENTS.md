# AGENTS.md

## 1. 项目目标

本项目是一个《十日终焉》主题的沉浸式资料站，核心不是“百科式堆砌”，而是把人物、事件、世界观和关系组织成可阅读的主脉络。

前端以 `src/` 为主，优先围绕以下阅读顺序组织内容：

1. 总馆：全局脉络
2. 事件馆：按时间轴看事件如何推动剧情
3. 人物馆：看人物定位、回响、能力与关系
4. 世界观馆：看世界结构、规则和真相
5. 关系馆：保留为辅助验证层，不作为主入口

---

## 2. 开发优先级

开发时遵循以下优先级：

1. `docs/plans/*.md`
2. `docs/AGENTS.md`
3. `memory/MEMORY.md`
4. `src/` 中现有实现与测试
5. 临时注释与 TODO

若发生冲突：
- 计划优先于默认实现
- AGENTS 约束开发方式与边界
- 不允许自行发明未在计划中定义的产品行为，除非是技术上必要的最小补充

---

## 3. 当前范围

### 本期必须完成
- 总馆主脉络展示
- 事件馆时间轴与事件卡
- 人物馆关系网络与人物档案
- 世界观馆分类图谱与解释层
- 资料清单与结构化数据同步
- 本地与 CI 的一致性验证

### 本期不做
- 真实后端服务接入
- 登录权限系统
- 商业化能力
- 复杂监控系统
- 额外不在计划内的关系馆扩张

---

## 4. 总体原则

### 4.1 分阶段交付
必须严格按 `docs/plans/` 中的阶段顺序推进。每个阶段应当：
- 可开发
- 可运行
- 可验证
- 可回归

### 4.2 接口先行
即使内部先用 mock，也要先把数据结构和展示接口定下来，避免后续推翻前后端联动方式。

### 4.3 内容链路优先
事件、人物、世界观之间必须能相互跳转，但默认展示要服务主线阅读，不要让所有信息同时抢主视觉。

### 4.4 以参考原型为准
设计和交互优先复用 `demo/` 的有效结构，不应随意重做信息架构。

### 4.5 资料分层优先
研究池、清单层、正式层和记忆层必须分开。正式页面只消费正式层或明确标记为 `待核` 的过渡数据；分层细则见 `docs/content-layering.md`。

---

## 5. 代码组织要求

建议使用如下模块划分：

- `src/components/`
- `src/`
- `docs/`
- `memory/`
- `scripts/`

建议拆分层次：

- 视图层：页面、馆页、网络画布
- 数据层：人物、事件、世界观、关系
- 约束层：布局、镜头、碰撞、边界
- 测试层：布局测试、相机测试、治理测试

---

## 6. 前端实现要求

### 6.1 前端基线
以前端原型和当前实现为基线，不重做整体结构。

### 6.2 前端最小要求
前端至少要支持：
- 总馆、人物馆、事件馆、世界观馆、关系馆之间的切换
- 人物馆的网络画布、缩放、拖拽、边界约束
- 事件馆的时间轴展开
- 世界观馆的宏观分类与层级展示

### 6.3 交互一致性
切换馆页时，必须同步刷新：
- 当前展示数据
- 选中状态
- 相机 / 缩放状态
- 关联高亮

---

## 7. 后端 / 接口预留要求

当前不接入真实后端，但如果需要预留接口，必须先写清楚：
- 数据获取入口
- mock 数据结构
- 后续替换点

不要在业务代码中把未来接口写死成临时逻辑。

---

## 8. 数据原则

### 8.1 所有主表必须包含
- `id`
- `createdAt`
- `updatedAt`

### 8.2 软删除优先

对于可编辑内容，优先保留软删除能力。

### 8.3 不直接绑定云厂商

如未来涉及存储，应通过抽象层实现，不把业务逻辑耦合到某个具体 OSS / S3。

---

## 9. CI / Docker 规则

### 9.1 CI 必须覆盖
- 治理文件存在性
- `npm run lint`
- `npm test`
- `npm run build`

### 9.2 Docker 目标

前端仓库只保留必要镜像：
- 生产预览镜像
- 测试镜像
- 本地测试编排

---

## 10. 每阶段完成标准

每个阶段完成后必须同时满足：

- 功能符合对应计划
- 可以本地启动运行
- 有最小可验证路径
- 不破坏前一阶段能力
- 代码已按模块归位
- 保留必要注释与 TODO

---

## 11. Codex 执行要求

Codex 在每次实现任务时应遵循：

1. 先阅读对应阶段计划
2. 明确本次只做当前阶段要求的内容
3. 优先补齐接口与数据结构
4. 再完成前后端联动
5. 完成后给出：
   - 改动文件清单
   - 已完成能力
   - 待补充项
   - 本地验证方式
