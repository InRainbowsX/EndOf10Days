# 十日终焉博物馆内容总表（审阅稿）

## 使用说明

这份文档只整理当前仓库里已经落下的数据，不额外扩写整本书设定。

审阅时建议重点看三件事：

1. 终焉阶段划分顺不顺。
2. 人物、事件、机制、结果的命名是否贴近你对小说的理解。
3. 哪些内容必须补，哪些内容现在就该删。

## 七、当前数据结构问题

| 问题 | 现状 | 建议 |
| --- | --- | --- |
| 命名重复 | `truth-line` 和 `endland` 都指向“终焉之地”；`co-conspirator-net` 和 `survival-alliance` 都指向主角团结构。 | 统一一套主名称，另一套只保留为展示文案或废弃。 |
| 阶段粒度不均 | 第1次终焉较实，第7次以后和终局偏抽象。 | 后续优先补中后段事件锚点，不急着扩 UI。 |
| 事件密度不足 | 现在能支撑图的事件节点太少。 | 后续优先增加“房间/关键博弈/关系重排”类事件。 |
| 真相层单薄 | 真相目前几乎只剩“终焉之地”一个聚合词。 | 后续拆成更明确的真相节点或认知节点。 |
| 终焉之前空缺 | 目前只是一个源头占位。 | 后续补人物初始状态、旧秩序、进入终焉前的背景。 |
| 关系语义不成体系 | 有“共谋 / 互补 / 默契 / 保护 / 压制”等标签，但没有统一分类标准。 | 后续可整理成“关系标本表”。 |
