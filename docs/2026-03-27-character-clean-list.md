# 十日终焉人物清单（2026-03-27 清理版）

说明：
- 本清单用于统一人物馆的数据底稿，不是最终文案，而是可直接回填页面和数据层的整理版本。
- `智力 / 战斗 / 辅助` 为馆内评估值，统一按 `1-5` 星处理，不视为原著官方数值。
- `回响` 只有在当前资料池里存在相对稳定公开口径时才写死；否则一律标记为 `待核`。
- `置信度` 分为 `高 / 中 / 待核`：
  - `高`：仓库已入数据层，且多份资料口径相对稳定。
  - `中`：仓库已入数据层，但部分字段仍主要依赖公开讨论归纳。
  - `待核`：文档里高频出现，但仍缺少稳定原文核对或字段口径不稳。

## 四、对当前页面数据的最小建议

这轮如果只做最小安全修改，建议只改这两类：

1. 把已确认回响从页面里的 `待核` 改成明确值。
2. 不改人物 schema，不在这轮把所有新增人物硬塞进 `archiveData.ts`。

原因：
- 现有人物馆 UI 已经依赖 `archiveNodes` 结构，贸然扩字段会波及多个测试。
- 回响映射目前是低风险、可立刻提升可读性的改动。
- 新人物更适合在下一轮和事件 / 世界观联动时一起补。
