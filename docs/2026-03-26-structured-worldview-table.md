# 十日终焉世界观总表

说明：
- 本表来自世界观资料池 1-200 条的重组。
- 按“规则层 / 结构层 / 真相层 / 主题层”四段组织，便于直接映射世界观馆。

| 世界观簇 | 覆盖条目 | 核心信息 | 建议页面落点 | 录入优先级 | 备注 |

| 终焉之地基础舞台 | 世界观 1-4, 121-123 | 终焉之地是封闭的人造秩序，不是自然灾后空间；十人空屋是最小世界模型。 | 世界观馆-总说明 | P0 | 应作为馆首页第一段 |
| 十日循环与第十一日复活 | 世界观 5-10, 101-103 | 死亡被改造成管理工具；复活与失忆共同构成统治机制。 | 规则层 | P0 | 核心设定，必须高亮 |
| 记忆权的不平等 | 世界观 8-10, 84-90, 103, 162, 192-199 | 回响者保留记忆，普通参与者被刷新，真正的不平等是“谁拥有历史连续性”。 | 规则层 / 结构层 | P0 | 建议作为关键世界观节点 |

| 问答、站位、计时等规则语言 | 世界观 17-19, 114-117 | 终焉偏好把人简化成可运算变量，语言和时间都是生死工具。 | 规则层 | P1 | 适合做知识补充 |

| 人地天三级与生肖体系 | 世界观 11-14, 51-60, 109-110, 181-189 | 等级不是单纯难度，而是权限、真相距离和可替换性的分层。 | 结构层 | P0 | 是世界观馆中轴之一 |

| 回响作为执念外化 | 世界观 81-90, 161-164 | 回响不是外挂，而是执念实体化；能力、记忆和人物伤痕被绑定在一起。 | 规则层 / 真相层 | P0 | 必须和人物馆回响字段对齐 |
