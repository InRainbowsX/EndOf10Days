# 十日终焉博物馆扩展内容稿

这份稿子用于给博物馆页面补内容，目标不是一次性写成最终定稿，而是先把`人物 / 事件 / 世界观 / 关系`四部分扩成可用资料池。

说明：
- 以下内容综合了当前仓库已有数据、公开书评、视频解读、贴吧时间线讨论和世界观拆解文章。
- 对于争议较大的细节，这份稿子优先保留“高频共识”，避免把二创或单一解读直接写死。

## 页面同步原则

### 总馆

- 保留完整终焉时间脉络
- 每段阶段卡继续展示：标题、核心人物、核心事件、推动机制、阶段结果

### 人物馆

- 独立页面
- 先展示索引墙
- 再展示重点人物大档案
- 后续补更多人物档案入口

### 事件馆

- 独立页面
- 头部主事件
- 事件身份卡
- 规则概要
- 事件演化图
- 全事件卡列表

### 世界观馆

- 独立页面
- 规则层 / 结构层 / 真相层
- 每层单独展板

### 关系馆

- 独立页面
- 关系类型总览
- 典型关系案例
- 心理基础与关联事件
