# 研究资料与正式内容分层规则

这份文档定义仓库里所有《十日终焉》内容的分层边界。目标只有一个：让研究过程可以继续扩张，但正式页面只消费已经定版的内容。

## 一、四层定义

### 1. 研究池

研究池保存所有原始来源与未定稿材料，包括：

- 原始摘录
- 章节抽样锚点
- 论坛 / 目录 / 评论型材料
- `待核` 的人物、事件、回响、关系

研究池的作用是“收集证据”，不是给页面直接消费。

### 2. 清单层

清单层负责把研究池整理成结构化表格或清单，包括：

- 结构化总表
- 优先级标记
- 待定字段
- 资料冲突与缺口

清单层允许存在 `待核`，但必须明确标注来源和置信度。

### 3. 正式层

正式层是页面直接消费的数据层，包括：

- `src/archiveData.ts`
- 页面内使用的派生数据
- 已通过测试和回归验证的展示结构

正式层只接受两类内容：

- 已定版内容
- 明确标记为 `待核` 的临时占位内容

### 4. 记忆层

记忆层存放长期稳定规则，包括：

- 开发约束
- 常见错误
- 资料晋升规则
- 事故记录

记忆层的作用是把一次次补丁经验变成长期防线。

## 二、晋升路径

研究资料不能直接跳到正式层，必须经过以下路径：

1. 原始摘录进入研究池
2. 研究池整理成清单层
3. 清单层补足证据、冲突说明和优先级
4. 达到定版标准后，晋升到正式层
5. 正式层同步到页面和测试

## 三、定版标准

以下情况可以视为进入正式层：

- 章节锚点和人物 / 事件 / 世界观节点已形成稳定共识
- 结构位置明确
- 与现有页面数据不冲突，或冲突已记录并处理
- 已有回归测试或检查项覆盖

以下情况保留在清单层或研究池：

- 来源不稳定
- 名称不统一
- 结构位置未定
- 仍需继续补证据

## 四、页面消费规则

页面只允许读取正式层，或读取清单层里明确标注的 `待核` 占位。

禁止：

- 直接把研究摘录写进页面正文
- 把未核实内容写死成最终结论
- 把清单层和正式层混用而不做标记

## 五、推荐文件职责

- `docs/`：清单、计划、冲突说明、正式规则
- `memory/`：长期规则、事故记录、工程约束
- `src/archiveData.ts`：正式层主数据
- `docs/issues/`：待处理问题与推进记录
