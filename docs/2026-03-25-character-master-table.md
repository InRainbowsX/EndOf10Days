# 十日终焉博物馆人物总表（第一版审阅稿）

## 说明

这份表不是最终定稿，而是 `用于搭建博物馆人物馆的数据底稿`。

整理原则：

1. 先基于当前仓库已出现的人物。
2. 再吸收可访问的公开讨论、人物盘点、时间线整理、角色分析中高频出现的人物。
3. 不把“所有有名字的人”都一口气拉进主馆，而是分成：
   - `一级人物：主脉络人物`
   - `二级人物：强关联关键人物`
   - `三级人物：专题人物 / 事件人物 / 组织人物`

`置信度` 说明：

- `高`：当前仓库已出现，且在公开讨论中高频出现
- `中`：公开讨论中高频出现，但我当前还没有基于原文做逐条核校
- `待核`：公开讨论里出现，适合留在数据库候选池，但需要后续回到原文确认

## 五、每个人物条目建议固定补哪些字段

为了后续补内容不乱，建议人物总表里的每个人物最终都要补齐这些字段：

| 字段 | 必填级别 | 说明 |
| --- | --- | --- |
| `name` | 必填 | 人物名 |
| `tier` | 必填 | 一级 / 二级 / 三级 |
| `positioning` | 必填 | 人物定位 |
| `initial_state` | 一级必填 | 初始状态 |
| `key_event_ids` | 一级必填 | 3-5 个关键事件 |
| `psychological_arc` | 一级必填 | 心理变化轨迹 |
| `relationship_arc` | 一级必填 | 关键关系变化 |

| `worldview_ids` | 一级推荐 | 所属世界观节点 |

| `debated_points` | 推荐 | 争议点 |
| `primary_links` | 必填 | 默认展示的关键跳转 |
| `secondary_links` | 推荐 | 扩展跳转 |
| `deep_links` | 推荐 | 深层互联 |

## 八、这份总表当前的使用方式

我建议你先用这份表做两轮筛选：

1. 先批：一级人物名单对不对，有没有缺、有没有不该进一级的。
2. 再批：二级和三级人物哪些要提前、哪些可以删。

这轮确认之后，我下一步就可以继续做：

- `人物馆正式录入模板`
- 或者直接开始补 `一级人物` 的完整人物档案

如果只做一步，我建议下一步直接补：

`齐夏、林檎、许流年、楚天秋、燕知春、余念安`

因为这 6 个人最能把人物馆的上限拉起来。
