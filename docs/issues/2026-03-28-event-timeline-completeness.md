# 事件馆按终焉阶段补全时间轴与游戏清单

## 问题目标

事件馆需要从“阶段目录”升级成“终焉阶段时间轴 + 游戏清单”。当前结构已经能看出主脉络，但事件密度不足，无法把整本书的推进关系完整铺开。

## 问题现象

- 某些终焉阶段事件过少，读者会感觉时间线稀疏。
- 关键游戏的入口没有单独列出，读者只能从阶段里反推。
- 事件与人物的跳转已经有了，但事件本身的链路还不够完整。

## 预期结果

- 每个终焉阶段都尽可能完整列出事件。
- 每个事件都能看出它推动了哪段剧情。
- 事件卡要保留时间轴顺序，不做随意打散。
- 每个事件都能点击回对应人物。

## 建议内容结构

1. 第几次终焉
2. 阶段内游戏 / 事件标题
3. 参与人物
4. 规则或关键机制
5. 剧情推动作用
6. 结果与下一阶段流向

## 验收标准

- 用户能沿时间轴读完整体脉络。
- 事件馆不再依赖少量代表事件撑版面。
- 后续只需要删减，不需要再补“主时间线骨架”。
