# 人物馆默认镜头偏移异常

## 问题现象

人物馆进入后，卡片网络默认落位偏右下，顶部和左侧留白明显过大，首屏看不到清晰的内容重心。

## 证据截图

![人物馆默认镜头异常](/Users/qitmac001629/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/wxid_nwj0wfpjwoya21_9920/temp/RWTemp/2026-03/10509f3f6f748d104052c5b456fb26d9.jpg)

## 复现步骤

1. 打开人物馆
2. 不拖拽、不缩放
3. 观察默认视口

## 预期结果

- 默认视口自动对准内容主体
- 人物卡片群应位于可视区域中部
- 卡片不得集中在右下角

## 实际结果

- 首屏可视区域大面积留白
- 内容重心偏离视口中心
- 用户需要手动拖动后才能看清主要节点

## 当前判断

根因更像是默认 camera / framing 计算错位，而不是节点碰撞或越界。

## 修复方向

- 在进入人物馆时，每次都重新按当前视口与内容边界计算相机
- 在离开人物馆时重置相机初始化标记，避免返回后沿用旧偏移
- 补回归测试，覆盖“离开再返回人物馆后仍居中”这一循环

## 回归验证

- 默认镜头按内容边界重新居中
- 拖拽后切走再返回，镜头会恢复到默认居中状态

## 处理顺序

1. 先在 issue 里固定现象和截图
2. 再复现根因
3. 再写最小修复方案
4. 再改代码
5. 再回归验证
