# 人物馆画布布局与补充人物折叠策略

## 问题目标

人物馆当前主画布承担了太多信息：人物节点、关系线、星级、标签、辅助人物都在同一个视觉层里。即使相机和边界已经修正，信息密度仍然偏高，后续一旦继续补人物，主视图会重新失控。

## 问题现象

- 主画布里人物数量一多，视觉重心会被补充人物拉散。
- 补充节点虽然有固定槽位，但在当前展示密度下仍然会抢主视图。
- 用户很难在第一眼分辨“中心人物 / 阵营核心 / 次级补充”。

## 预期结果

- 主画布只保留少量核心人物。
- 次级人物有明确折叠层，不直接挤在主画布。
- 人物馆默认进入后，读者能清晰识别阵营结构和主轴人物。

## 可能方案

1. 主画布只保留中心人物和每个阵营的核心节点。
2. 次级人物折叠成“更多人物”入口，点击后展开独立列表。
3. 关系线只保留强关系，弱关系隐藏到详情层。
4. 星级和能力值继续压缩到极简摘要，不再扩展正文。

## 验收标准

- 主画布默认不拥挤。
- 核心人物和补充人物的视觉层级清楚。
- 后续新增人物不会让主画布再一次失控。
