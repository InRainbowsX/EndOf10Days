# 世界观馆分类与宏观结构定版

## 问题目标

世界观馆需要从“信息展示”升级成“宏观结构总图”。当前方向已经有规则层、结构层、真相层，但还需要把分类口径和层级关系定死，避免以后越补越散。

## 问题现象

- 分类如果不统一，后续补条目会不断跑偏。
- 史诗感依赖宏观结构，不依赖碎片设定。
- 读者需要先理解“世界是如何压住人物命运的”，再看具体设定。

## 建议定版的分类

1. 世界壳层：终焉之地是什么。
2. 管理机制：十日循环、回响、失忆、复活等如何运作。
3. 权力结构：天 / 地 / 人 / 生肖 / 高位秩序如何分层。
4. 终局重写：第二站、新世界、重解释如何回收前文。

## 预期结果

- 世界观馆先展示宏观骨架，再进入具体内容。
- 每个分类都能挂回事件馆和人物馆。
- 分类口径稳定，后续补充不会打散主结构。

## 验收标准

- 读者能一眼看出世界观的“壳层 / 机制 / 结构 / 重写”。
- 不再把世界观馆做成设定词堆。
- 后续新增内容都能自然落入四大分类之一。
