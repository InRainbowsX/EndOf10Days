### 5. 世界观的推荐表达方式

| 表达对象 | 推荐写法 |
| --- | --- |
| 终焉之地 | 不是背景地点，而是统摄人物、事件、规则的外层结构 |
| 十日循环 | 不是简单回档，而是清洗、重投、维稳的统治周期 |
| 回响 | 不是外挂，而是创伤、记忆和结构渗透的接口 |
| 生肖体系 | 不是单纯难度分类，而是权力与真相距离的分层 |
| 桃源计划 | 不是终焉同义词，而是被篡改、被劫持的原始计划 |
| 新世界 | 不是通关结算，而是世界被重新建造 |

## 四、建议的回填顺序

1. 先把事件馆补到“按阶段完整展开”的粒度。
2. 再把世界观馆补成“四层总图”。
3. 同步把人物馆的 `待核` 回响、能力值和关键关系补齐。
4. 最后再做删减，不在这一轮追求精简。

## 五、当前可以直接落到页面的数据原则

- 事件馆：每个事件必须至少有 `参与人物 / 规则 / 过程 / 后果 / 推动作用`。
- 人物馆：每个人物必须至少有 `定位 / 回响 / 星级 / 关键关系 / 关键事件`。
- 世界观馆：每个节点必须至少有 `层级归属 / 作用 / 与人物和事件的连接`。
- 所有不确定内容统一标 `待核`，不在正文里硬写成最终定论。
