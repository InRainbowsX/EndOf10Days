# 十日终焉博物馆事件总表（第一版审阅稿）

## 说明

这份表用于给 `事件馆` 打底，不是最终事件正文。

整理原则：

1. 先保留当前仓库已出现的关键事件。
2. 再结合公开讨论中高频出现的“初始房间 / 十二生肖游戏 / 神兽 / 双龙统治 / 列车 / 终局回收”等主脉络事件群补齐框架。
3. 不把所有章节都拆成事件，而是优先保留：
   - `一级事件：主脉络事件`
   - `二级事件：关键局 / 关键房间 / 关键重排事件`
   - `三级事件：专题事件 / 世界观事件 / 终局回收事件`

`置信度` 说明：

- `高`：当前仓库已存在，或公开资料高度一致
- `中`：公开资料高频出现，但需要后续回到原文精校
- `待核`：公开讨论可见，但事件范围、名称或权重还需要原文校正

## 六、事件馆的知识补充建议

你前面要求把“规则、文学知识、知识点”等内容也放进事件里，我建议事件馆统一建立一列 `knowledge_notes`，可收纳这些类型：

| 类型 | 示例 |
| --- | --- |
| 博弈论 | 囚徒困境、纳什均衡、零和博弈 |
| 心理学 | 群体恐慌、认知偏差、服从与权威 |
| 社会学 | 权力复制、秩序崩塌、群体分层 |
| 文学性 | 象征、隐喻、叙事反转、结构回收 |
| 思想命题 | 人性异化、生存伦理、循环困境 |

建议：

- 一级事件必须有 `knowledge_notes`
- 二级事件有则补
- 三级事件可作为专题汇总

## 九、这份总表当前的使用方式

我建议你先按下面顺序批：

1. 一级事件名单对不对，有没有明显缺失的主脉络事件。
2. 哪些二级事件应该提前进首页，哪些应该退回候选池。
3. 哪些三级事件应该作为“事件群”存在，而不是独立事件。

这轮确认之后，我下一步可以继续做两件事中的一个：

1. 直接开始补 `一级事件` 的正式事件档案
2. 把 `人物总表 + 事件总表` 合并成第一版结构化数据库草稿

如果只做一步，我建议先补：

`初始房间 / 主角团雏形生成 / 真相逼近 / 列车与终局回收`

因为这四个事件最能快速立起事件馆的骨架。
